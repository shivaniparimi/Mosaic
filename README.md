# Mosaic
A native iOS productivity app that brings together the essential pieces of modern productivity into one effortless experience.

## Features

- **Today** — Tasks on the daily.
- **Inbox** — Similar to the Notes app — jot down upcoming tasks without a date that need to get done.
- **Upcoming** — Syncs with your calendar and shows your upcoming schedule.
- **Search** — Search by task or tag.
- **Settings** — Appearance and syncs.

## How It Works

- **Natural Language Task Entry** — Create structured tasks by typing naturally, such as "Email Haley tomorrow at 2 PM." No ML model or external API — a hand-written parser built on `NSRegularExpression` and word-boundary matching detects dates, times, time ranges, recurring weekday patterns, and `#tags` as you type, then strips the matched text out of the title.
- **Photo & File Attachments** — Keep screenshots, PDFs, and reference materials directly connected to the task they support. Photos come in through `PhotosUI`'s `PhotosPicker`, other files through `.fileImporter`; both are copied into the app's own Documents directory and tracked as a `@Relationship` on the task's SwiftData model.
- **Location-Based Reminders** — Trigger reminders based on arriving at or leaving specific locations. Built on `CoreLocation` geofencing (`CLLocationManager` + `CLCircularRegion`), so alerts fire in the background, even when the app isn't open.
- **Calendar & Reminders Sync** — Stay in sync with your existing Calendar and Reminders apps. Read-only `EventKit` (`EKEventStore`) integration pulls events and reminders directly into the Upcoming view alongside your tasks.

## Tech Stack

- **Language:** Swift 6 with strict concurrency (actor isolation via `@MainActor`)
- **UI:** SwiftUI, `@Observable` ViewModels
- **Persistence:** SwiftData, with a versioned schema (`SchemaV1` → `SchemaV2`) and migration plan
- **System frameworks:** `EventKit`, `CoreLocation`, `PhotosUI`, `UserNotifications`
- **Testing:** Swift Testing (`@Test`), 227 tests running against in-memory SwiftData stores
- **Tooling:** [XcodeGen](https://github.com/yonaskolb/XcodeGen) generates the `.xcodeproj` from `project.yml` — the project file itself isn't checked in

## Architecture

- `Domain/` — protocols and models, no framework dependencies (`TaskRepository`, `CalendarSyncService`, etc.)
- `Data/` — the concrete implementations, one folder per integration (`SwiftData/`, `Calendar/`, `Location/`, `Notifications/`, `Attachments/`, `AI/`)
- `Features/` — one SwiftUI View + `@Observable` ViewModel per screen (`Today/`, `Inbox/`, `Upcoming/`, `Search/`, `Settings/`, ...)
- `App/` — `AppDependencyContainer` wires every dependency by hand (no DI framework); separate `.live()`/`.preview()` factories keep tests and SwiftUI previews off real device state

## Getting Started

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is not checked in, so a fresh clone needs to generate it first.

1. Install XcodeGen: `brew install xcodegen`
2. Generate the Xcode project: `xcodegen generate`
3. Open `Mosaic.xcodeproj` in Xcode, or build from the command line:
   ```
   xcodebuild -project Mosaic.xcodeproj -scheme Mosaic -destination 'platform=iOS Simulator,name=iPhone 17' build
   ```
4. Run tests:
   ```
   xcodebuild test -project Mosaic.xcodeproj -scheme Mosaic -destination 'platform=iOS Simulator,name=iPhone 17'
   ```

Re-run `xcodegen generate` whenever source files are added or removed, or after editing `project.yml`.
