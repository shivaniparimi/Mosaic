# Mosaic
A native iOS productivity app that brings together the essential pieces of modern productivity into one effortless experience.

## Features

- **Today** — Tasks on the daily.
- **Inbox** — Similar to the Notes app — jot down upcoming tasks without a date that need to get done.
- **Upcoming** — Syncs with your calendar and shows your upcoming schedule.
- **Search** — Search by task or tag.
- **Settings** — Appearance and syncs.

## Getting Started

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is not checked in, so a fresh clone needs to generate it first.

1. Install XcodeGen: `brew install xcodegen`
2. Generate the Xcode project: `xcodegen generate`
3. Open `Mosaic.xcodeproj` in Xcode, or build from the command line:
   ```
   xcodebuild -project Mosaic.xcodeproj -scheme Mosaic -destination 'platform=iOS Simulator,name=iPhone 17' build
   ```
4. Run tests:
   ```
   xcodebuild test -project Mosaic.xcodeproj -scheme Mosaic -destination 'platform=iOS Simulator,name=iPhone 17'
   ```

Re-run `xcodegen generate` whenever source files are added or removed, or after editing `project.yml`.
